# Prop Dashboard

Prop-Firm-Dashboard für 2-Step-Konten (100K): Markt & News mit News-Sperren pro Firma, Regeln, Capital-Critic-Abgleich, Payout-Termine, Risiko-Calculator mit Pre-Trade-Ampel und Regel-Pop-up, Consistency-Rechner, Tracker (Payout-Historie, Programm-Ausstiege, Verstoß-Zähler, USD⇄EUR) und Beweis-Log pro Streitfall.

**Live:** https://timurozn.github.io/prop-dashboard/

Basiert auf dem Prop Dashboard von Flenkenz (elkhatoutimohamed-rgb.github.io/prop-dashboard).
Regeln Stand Oktober/November 2026 – keine Gewähr, vor jedem Trade oder Payout die offizielle FAQ der Firma gegenchecken.
Eingaben (Rechner, Payouts, Tracker, Beweis-Log inklusive Dateien) bleiben nur im Browser des jeweiligen Nutzers gespeichert – nichts davon landet im Repo.
